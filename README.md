# Нейро-стенографист (NeuroSteno)

Android-приложение, которое **полностью на устройстве, без интернета** превращает запись разговора в текст, определяет говорящих и выдаёт структурированную расшифровку с временными метками.

Решение для хакатона Nuclear IT Hack (НИЯУ МИФИ), задача от HEX.TEAM / КСиТ.

## Что умеет

- Импорт аудиозаписи из памяти устройства (mp3, m4a, wav и другие форматы, которые читает Android).
- Распознавание русской речи со знаками препинания (GigaAM v3, sherpa-onnx).
- Автоматическое определение числа говорящих и разделение реплик (pyannote + CAM++).
- Временные метки каждой реплики (миллисекунды).
- Просмотр расшифровки в приложении, воспроизведение записи с переходом к нажатой реплике, индикатор прогресса.
- Экспорт в **JSON** строго по ТЗ (`{"transcript":[{"speaker_id","start_ms","end_ms","text"}]}`) и в TXT.
- Локальная LLM (Qwen2.5-0.5B-Instruct) делает краткое резюме разговора после расшифровки.
- Нет разрешения INTERNET: данные физически не покидают телефон.

## Быстрый старт

1. Скачайте `app-debug.apk` из раздела **Releases** этого репозитория (все модели уже внутри, около 0,9 ГБ).
2. Установите на Android-устройство или эмулятор (перетащите файл на окно эмулятора или `adb install app-debug.apk`).
3. Откройте приложение, дождитесь надписи «Модели загружены, работаю офлайн».
4. Нажмите «Выбрать аудиофайл», выберите запись, дождитесь результата.
5. «Сохранить JSON» / «Сохранить TXT» для экспорта, «Резюме (локальная LLM)» для краткого содержания.

Подробная инструкция по сборке из исходников: [`src/README.md`](src/README.md).

## Используемые модели

| Назначение | Модель |
|---|---|
| Распознавание речи | GigaAM v3 CTC с пунктуацией, int8 (`sherpa-onnx-nemo-ctc-punct-giga-am-v3-russian-2025-12-16`) |
| Сегментация речи по говорящим | pyannote segmentation 3.0 (`sherpa-onnx-pyannote-segmentation-3-0`) |
| Эмбеддинги говорящих | 3D-Speaker CAM++ (`3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced`) |
| Локальная LLM | Qwen2.5-0.5B-Instruct, int8, формат MediaPipe `.task` |
| Рантайм | sherpa-onnx 2.0.1 (ONNX Runtime), MediaPipe tasks-genai |
