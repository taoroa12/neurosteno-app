# Инструкция по запуску и сборке проекта

Платформа: **mobile / android** (`src/mobile/android`).

## Требования

- Android Studio (актуальная версия), JDK берётся из Android Studio.
- Android SDK: compileSdk 37, minSdk 26.
- Git и **Git LFS** (`git lfs install` до клонирования, иначе модель распознавания не скачается).
- Свободно около 5 ГБ на диске.
- Для запуска: эмулятор или устройство Android 8.0+, рекомендуется 4 ГБ ОЗУ; ABI arm64-v8a или x86_64.

## Сборка из исходников

1. Клонируйте репозиторий (с LFS):
   ```
   git lfs install
   git clone <URL репозитория>
   ```
2. Модели распознавания и диаризации лежат в репозитории в `src/mobile/android/app/src/main/assets/models/` (`asr`, `seg`, `emb`). Файл `asr/model.onnx` (около 214 МБ) хранится в Git LFS.
3. **Модель LLM в репозиторий не входит** из-за размера. Скачайте файл
   `Qwen2.5-0.5B-Instruct_multi-prefill-seq_q8_ekv1280.task` (547 МБ) со страницы
   `huggingface.co/litert-community/Qwen2.5-0.5B-Instruct`, создайте папку
   `src/mobile/android/app/src/main/assets/models/llm/` и положите туда файл под именем
   `qwen2.5-0.5b-q8.task`.
4. Откройте папку `src/mobile/android` в Android Studio, дождитесь Gradle Sync.
5. Сборка APK: в терминале Android Studio
   ```
   .\gradlew.bat assembleDebug
   ```
   Результат: `app/build/outputs/apk/debug/app-debug.apk` (около 0,9 ГБ).
6. Запуск: кнопка Run в Android Studio либо установка APK на эмулятор перетаскиванием.

Готовый APK, собранный по этой инструкции, находится в разделе Releases репозитория.

## Использование

1. После запуска приложение один раз загружает модели в память (несколько секунд).
2. Выберите число говорящих или оставьте «Авто».
3. Нажмите «Выбрать аудиофайл» и укажите запись из памяти устройства.
4. Дождитесь окончания обработки: отображаются этап и процент.
5. Расшифровка появится списком реплик. Нажатие на реплику воспроизводит запись с этого места.
6. «Сохранить JSON» и «Сохранить TXT» открывают системный диалог сохранения файла.
7. «Резюме (локальная LLM)» формирует краткое содержание разговора (при первом нажатии модель копируется во внутреннюю память приложения, это занимает до минуты).
