# Формат выходных данных

## JSON (экспорт по кнопке «Сохранить JSON»)

Формат полностью соответствует ТЗ.

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `transcript` | array | Массив реплик в порядке времени |
| `speaker_id` | string | Идентификатор говорящего: `speaker_1`, `speaker_2`, … по порядку появления в записи |
| `start_ms`, `end_ms` | integer | Начало и конец реплики в миллисекундах от начала записи |
| `text` | string | Текст реплики со знаками препинания |

Кодировка UTF-8.

## TXT (экспорт по кнопке «Сохранить TXT»)

Удобный для чтения формат, по строке на реплику:

```
[00:03 – 00:11] Спикер 1: Барсик, коллеги, начинаем заседание. Первый вопрос: охрана склада сметаны.
[00:11 – 00:21] Спикер 2: Мусенька, у нас есть проблема: за последнюю неделю пропало три банки.
```
