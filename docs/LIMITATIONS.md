# Ограничения решения

## Поддерживаемые условия

- Android 8.0 (API 26) и выше; архитектуры arm64-v8a и x86_64.
- Рекомендуется 4 ГБ ОЗУ; приложение запрашивает увеличенную кучу (`largeHeap`).
- Языки: русский (основной), английский (в пределах возможностей модели GigaAM, ориентированной на русский).
- Вход: аудиофайл из памяти устройства (форматы, которые декодирует Android: mp3, m4a, wav и др.).
- Работа полностью офлайн.

## Известные ограничения

- **Скорость.** RTF зависит от устройства. На x86_64-эмуляторе без аппаратного ускорения на ПК разработчика получено 0,2–0,5 (первый запуск после установки может быть медленнее, до 0,9). На реальных ARM-устройствах значение будет другим.
- **Качество звука.** При сильном шуме, музыке на фоне и плохой дикции растёт число ошибок распознавания. Для синтетических записей низкого качества наблюдались обрезанные слоги.
- **Диаризация.** Похожие голоса могут быть объединены в одного говорящего, а при плохом звуке один голос может быть разбит на нескольких (в автоматическом режиме есть защита от раздробления, но она эвристическая). Число говорящих можно задать вручную (2–5).
- **Одновременная речь.** При перебиваниях реплика приписывается одному говорящему, одновременная речь нескольких людей не разделяется.
- **Очень короткие реплики** (до 0,45 с) отбрасываются.
- **Резюме LLM.** Модель Qwen2.5-0.5B небольшая и может ошибаться в деталях и именах. Резюме носит справочный характер и не заменяет расшифровку.
- **Размер APK** около 0,9 ГБ из-за встроенных моделей.

## Что не входит в текущую версию

- Запись с микрофона из интерфейса (только импорт файла).
- Распознавание в реальном времени.
- Сохранение истории расшифровок.
- Редактирование расшифровки и повторная обработка фрагментов.
- Поддержка iOS и других платформ.

## Риски демонстрации

- Первый запуск после установки: загрузка моделей и «холодный» JIT замедляют первую обработку.
- Первое нажатие на «Резюме» копирует LLM во внутреннюю память приложения (до минуты).
- На устройстве должно быть не менее 2 ГБ свободного места для установки APK и копии LLM.

## Дальнейшее развитие

- Запись с микрофона и история расшифровок.
- Более точная диаризация собственной кластеризацией эмбеддингов.
- Ускорение за счёт аппаратных возможностей устройства (NNAPI, GPU).
- Более крупная LLM для резюме и извлечения задач.
- Редактирование расшифровки с повторной обработкой отдельных фрагментов.
