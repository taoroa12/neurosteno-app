# Методика и результаты тестирования

## Методика

- Устройство: Android-эмулятор (Medium Phone, Android 16 / API 36.1), 4 ГБ ОЗУ, архитектура x86_64, на ПК разработчика (эмулятор организаторов по ТЗ ARM; на нём результаты могут отличаться).
- Приложение: `app-debug.apk`, установленный на чистый эмулятор (Wipe Data) перетаскиванием.
- Режим: число говорящих «Авто».
- Метрика скорости: RTF = время обработки / длительность записи (отображается в приложении).
- Проверка корректности: визуальное сравнение текста с исходным сценарием, проверка числа говорящих и формата JSON.
- Тестовые записи: одна запись реальной речи и несколько синтетических диалогов, созданных генерацией речи (нейросетевой синтез). Часть синтетических записей содержит музыку и фон низкого качества, что используется как сложный случай.

## Наблюдения и внесённые исправления

1. Падение приложения при открытии файла: нативный колбэк прогресса диаризации (`NoSuchMethodError`). Колбэк убран.
2. На записях низкого качества автоматический режим находил 7 и 19 говорящих (раздробление голосов). Добавлено уточнение диаризации при числе говорящих больше 5; после этого на тех же записях найдено по 3.
3. На записи с перекрывающимися сегментами реплики дублировались у двух говорящих. Добавлено разделение перекрытий пополам и ограничение запаса по краям.
4. Обрывки вроде «Музик.» отфильтрованы по минимальной длине отрезка и наличию букв.
5. Формат JSON проверен вручную: поля `transcript`, `speaker_id` (строка `speaker_N`), `start_ms`, `end_ms` (целые), `text`.
6. Установка и работа APK проверены на чистом эмуляторе (после Wipe Data): расшифровка, экспорт JSON и TXT, воспроизведение, резюме.

## Резюме локальной LLM

Время: 11–30 с на запись длиной 1–3 минуты (эмулятор без GPU). Пример для записи «Дело о трёх банках сметаны»: «Барсик, коллеги, давайте заседание. Охрана склада сметаны — проблема за последнюю неделю. Рыжик проверял замки, но три банки исчезли. … Мусенька предложила вторую смену, увеличив паёк на одну рыбку.» Мелкие неточности (имя «Барсинка») встречаются из-за небольшого размера модели.

## Что не проверено

Формальный WER по эталонным расшифровкам не рассчитывался (эталонов нет). Замеры на ARM-устройстве не проводились.
